# Neon Sweep (Minesweeper-Style PWA)

Neon Sweep is a **quick launchable browser game** inspired by classic Minesweeper, with updated modern visuals and responsive controls.

## Quick Start
1. Open `Index.html` in a modern browser.
2. Pick a difficulty.
3. Left click to reveal cells, right click to flag suspected mines.
4. Clear all safe tiles to win.

## Features
- First click is always safe.
- Easy / Medium / Hard presets.
- Live HUD: mines left, timer, and revealed count.
- Offline-ready PWA support via service worker.

## PWA
- Includes `Service-worker.js` and `manifest.webmanifest`.
- Can be installed as a standalone app on supported browsers.
